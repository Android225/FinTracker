## Настройка токена доступа

Для работы приложения необходим персональный токен API.

1. Получите свой токен доступа.
2. Откройте файл `local.properties` в корне проекта.
3. Добавьте строку:

```properties
SHMR_AUTH_TOKEN=ваш_токен

Токен указывается без кавычек и без префикса Bearer
```
Пример:
```
sdk.dir=C\:\\Users\\User\\AppData\\Local\\Android\\Sdk
SHMR_AUTH_TOKEN=your_personal_token
```

```
Файл local.properties игнорируется Git, поэтому персональный токен не попадёт в репозиторий.
После изменения токена необходимо пересобрать и переустановить приложение, поскольку значение добавляется в BuildConfig во время сборки.
```
